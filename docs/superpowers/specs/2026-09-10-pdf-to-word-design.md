# PDF 转 Word 桌面工具设计规格

## 目标与边界

构建一个面向学校 Windows 电脑的简体中文桌面工具。发行包无需 Python、管理员权限或网络连接，可批量把文字型、扫描型和混合型 PDF 转换为同目录同名 DOCX。核心质量目标是审计底稿和财务表格的可编辑性，而不是像素级复刻或把整页作为图片嵌入 Word。

首个版本支持未加密或可直接打开的 PDF。密码破解、手写体识别、复杂公式重建和任意嵌套表格不在首版范围内。

## 技术选择

- Python 3.11。
- PySide6 提供拖拽、多选、线程安全信号、取消和中文 GUI。
- pypdfium2 负责 PDF 页面渲染，避免依赖系统 Poppler。
- pdfplumber 负责文字、图片、线条和矢量表格结构提取。
- rapidocr 与 onnxruntime 提供离线中英数字 OCR。
- OpenCV 提取扫描表格的横纵线和单元格区域。
- python-docx 生成段落、图片、分页符和真正的 Word 表格。
- PyInstaller onedir 生成 Windows 便携目录。

## 架构

`app/pdf` 打开 PDF、逐页分类并生成标准页面模型；`app/ocr` 延迟加载离线模型并把 OCR 框转换为统一文字框；`app/table` 从矢量线或图像线条恢复网格，把文字分配到单元格并推断横向、纵向合并；`app/word` 把页面模型写成 DOCX；`app/converter.py` 负责编排、逐页容错、进度和取消；`app/ui` 只负责展示和收集用户操作。

核心中间模型包括 `TextBlock`、`TableCell`、`TableData`、`ImageBlock`、`PageContent`、`ProgressEvent` 和 `ConversionResult`。坐标统一使用页面相对比例，避免渲染 DPI 影响布局计算。

## 页面处理流程

1. 读取每页字符、单词、图片覆盖率和页面面积。
2. 有效字符少于阈值或字符覆盖率过低时标记为 OCR，否则直接提取。
3. 文字页优先从 PDF 的矢量线和文字坐标恢复表格；表格外文字按从上到下、从左到右排序。
4. OCR 页以 220 DPI 渲染，先检测表格线，再执行 RapidOCR；OCR 框按中心点归入单元格。
5. 缺失的内部边线用于推断合并单元格；冲突时保守地保留独立单元格。
6. 非表格图片可单独插入。每个源页之后添加分页符，最后一页除外。
7. 单页异常写入中文日志并继续下一页；整份文件只在无法打开或无法写出时失败。

## 离线模型与发行

源码中的 `models/manifest.json` 固定模型文件名、来源和 SHA-256。构建脚本优先从已安装 RapidOCR 包复制模型，缺失时仅在 GitHub Actions 构建阶段下载并校验。运行时配置必须使用发行目录中的模型路径，且禁止调用下载逻辑。

PyInstaller 配置显式收集 PySide6 插件、pypdfium2、onnxruntime DLL、RapidOCR 数据文件和 `models/`。输出目录命名为 `PDF转Word-Windows`，随后打包为 `PDF转Word-Windows.zip`。

## GUI 与生命周期

主窗口包含拖拽区、选择单个/多个 PDF 按钮、文件列表、自动识别扫描件与保留表格结构复选框、固定输出位置说明、开始/取消按钮、当前文件、页码、转换方式、总进度、状态和日志。

转换在单个工作线程中串行处理文件，避免多个 ONNX 会话争抢内存。窗口关闭时设置取消标志并等待工作线程结束；应用不创建子进程，因此关闭后不残留后台进程。

视觉采用浅灰背景、白色内容面板、深蓝主操作色和克制的财务工作台语义。系统中文字体优先使用 Microsoft YaHei UI，状态数据使用 Consolas。拖拽区是唯一显著视觉元素。

## 测试与验收

- 单元测试覆盖页面分类、阅读顺序、文字归格、合并区域、输出命名、取消和中文错误。
- 集成测试程序化生成文字 PDF、财务表格 PDF、扫描表格 PDF、混合 PDF 和损坏 PDF。
- DOCX 测试同时检查 ZIP/OOXML 有效性、段落、表格、合并单元格、图片和分页符。
- GUI 冒烟测试使用 Qt offscreen 平台验证拖入文件、按钮状态和线程结束。
- macOS 本地验证 Python 流程与测试；Windows 构建由 GitHub Actions 验证 PyInstaller 产物、模型存在和 exe 启动探针。

## 已知限制

表格恢复采用启发式算法。无边框表格、旋转页面、跨页合并表格、非常复杂的多级表头和低清晰度扫描件可能需要人工调整。程序在日志中明确标记降级处理，但不会把整页截图作为成功的表格转换结果。
